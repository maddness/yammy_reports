# Output Examples

This folder contains example PDFs generated by the Yammy Reports system.

## Example Files

### invoice.pdf
Generated from:
- **Config**: `configs/invoice_report.json`
- **Data**: `examples/invoice_data.json`

A professional invoice template demonstrating:
- Company branding header
- Invoice numbering and dates
- Customer billing information
- Itemized services with pricing
- Total calculation
- Footer with payment terms

### sales.pdf
Generated from:
- **Config**: `configs/sales_report.json`
- **Data**: `examples/sales_data.json`

A multi-page sales report showcasing:
- Branded cover page with custom background color
- Executive summary page
- Key metrics display (revenue, orders, average order value)
- Top products breakdown with visual styling
- Professional layout with custom fonts and spacing

## Regenerating Examples

To regenerate these example PDFs, run:

```bash
# Activate virtual environment
source venv/bin/activate

# Generate invoice
python generate_report.py configs/invoice_report.json examples/invoice_data.json output/invoice.pdf

# Generate sales report
python generate_report.py configs/sales_report.json examples/sales_data.json output/sales.pdf
```
